# Read the lift diagram

The ring is an upstairs group orbit at one fixed sphere point. A marker records the lift of the endpoint. Choosing a pole places all deck translates on that circle. At a nonpolar point, the nonidentity translates belong to other sphere slices. The initial circle in the covering manifold contracts by Kotschick's theorem.

Open `index.html` in a local browser. Select the sphere point and deck-group order, vary the number of circuits, and rotate the schematic. When the order is three, the polar endpoints read 1, 2, 0 after one, two, three circuits. The nonpolar lift closes on its first circuit. The static GIF animates this order-three comparison. Run `python3 visualization/render.py` with Pillow to regenerate it.
